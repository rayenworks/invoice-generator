# Invoice Generator

A website where you make an invoice, edit it right on the page, and download it as a PDF. No sign-up, no server. It all runs in your browser.

**Live:** [https://your-project.vercel.app](https://invoice-generator-plum-alpha.vercel.app/)

## What it does

- Pick one of 10 invoice designs (Classic, Studio, Glass, Ledger, Sheet, Tinted, Playful, Editorial, Brutalist, Corporate).
- Click any text on the invoice to change it
- Add and remove items. Subtotal, tax and total update as you type
- Switch the currency ($, €, £, DA, ¥)
- Download the invoice as a PDF
